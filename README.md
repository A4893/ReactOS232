# Full Stack Web Application

This project is a work-in-progress full stack website that combines a frontend built with modern web technologies and a backend powered by Node.js and Express. The main goal of this project is to create a dynamic web application where the client interface and server logic work seamlessly together.

## Project Structure

- **src/**  
  Contains the frontend code (HTML, CSS, and JavaScript). This is where the client-facing part of the website is developed, including the layout, design, and user interface interactions.

- **server.js**  
  Acts as the entry point for the backend server. It uses Node.js and Express to handle API routes, server logic, and communication with the frontend.

## Current Progress

Both the frontend and backend components are functional in isolation. The frontend handles the UI, and the backend manages API routes and data handling. Work is currently focused on **integrating the two sides** so that the website can successfully send and receive real data between the client interface and the Express backend.

Future updates will include:
- Refining the communication between frontend and backend through REST API endpoints.
- Implementing database connectivity and authentication.
- Improving deployment readiness.
